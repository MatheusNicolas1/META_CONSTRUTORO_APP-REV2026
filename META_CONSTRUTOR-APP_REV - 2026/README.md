# Meta Construtor App (Rev 2026)

Application for managing construction projects, RDOs, and resources.

## Prerequisites
- Node.js (v18+)
- Supabase Account/Project

## Setup

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Environment Variables:**
   Create a `.env` file in the root directory based on `.env.example` (if available) or add:
   ```env
   VITE_SUPABASE_URL=your_supabase_url
   VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
   ```

3. **Run Development Server:**
   ```bash
   npm run dev
   ```

## Build for Production

1. **Build:**
   ```bash
   npm run build
   ```

2. **Preview:**
   ```bash
   npm run preview
   ```
