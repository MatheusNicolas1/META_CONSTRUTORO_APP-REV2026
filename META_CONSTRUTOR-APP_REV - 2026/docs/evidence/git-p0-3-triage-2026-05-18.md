## Bloqueio

Nao foi criado commit nem tag de release.

Motivo: muitos artefatos indevidos ja estavam staged antes desta etapa. Remover do stage com `git restore --staged` seria uma mudanca no indice compartilhado e pode desfazer uma selecao feita anteriormente pelo usuario. Tambem ha muitas mudancas de produto/Supabase sem revisao suficiente para afirmar que todas pertencem ao mesmo release.

## Proxima decisao necessaria

Definir a politica para limpar o indice:

1. Autorizar desstage apenas de artefatos locais claramente indevidos (`.playwright-cli`, `output`, `test-results`, `.zip`, `supabase/.temp`, `*.tsbuildinfo`, timestamps Vite e screenshots).
2. Revisar os arquivos de produto/Supabase restantes por grupos antes de criar o commit.
3. So depois rodar validacoes finais e criar commit/tag.
